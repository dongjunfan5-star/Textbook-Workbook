# 数学分析讲义做题本

[下载正式做题本](main.pdf)：三册合一本，18 章，1762 道最终题目，468 页（含说明与目录），通常每页 4 题，长题按实际高度单独安排。

对应源文件为《数学分析讲义（第一册）》《数学分析讲义（第二册）》《数学分析讲义（第三册）》。共核查 910 个 PDF 物理页面，其中 874 页正文完成 OCR 与内容核对，36 页封面、目录等非正文页面按来源清单明确排除。1550 个题目单元按每组最多 3 个小问拆分后得到 1762 题。

内容采用文字、LaTeX 公式和必要配图。只显示最终题号；每题记录源文件及首次出现的 PDF 物理页码。“改写”表示将说明性例子整理为明确问题，“校订”表示对原文条件作实质修正；具体依据见 `data/curated.json` 的校对说明。

## 使用与源码

- `main.pdf`：可以直接阅读、打印的完整做题本。
- `main.tex`、`chapters/`、`figures/`：可独立重新编译的源码，使用 XeLaTeX，至少编译两次至目录稳定。
- `data/curated.json`：合并后的校对数据，是重新生成章节的入口。
- `data/problems.json`：按最终编号组织的题目，以及源文件、首次出现页码和校对信息。
- `qa/`：当前正式版本的构建及检查记录；跨项目来源覆盖与发布检查见根目录 `qa/`。

原始教材和 OCR 缓存不随仓库分发。直接编译 LaTeX 不需要原始教材；运行构建脚本从校对数据重新生成时，需要自行提供校验值一致的原始教材。完整环境与命令见 [仓库说明](../README.md)。
