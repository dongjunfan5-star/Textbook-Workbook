# 数学分析教程做题本

上下册合订，共 18 章和附录 A，1811 道最终题目，615 页（含说明与目录）。常规每页 3 题，长题可以单独占页。[下载 PDF](main.pdf)

对应源文件为《数学分析教程 上册（数分A教材）》和《数学分析教程 下册（数分A教材）》。两册共 956 个源 PDF 物理页，其中 859 页正文与附录完成 PaddleOCR 与原图校对。1614 个题目单元按每组最多 3 个小问拆分，保留校对后的文字、公式及必要配图。跨页题记录首次出现的物理页码。

- `main.tex`、`chapters/` 和 `figures/` 可直接用 XeLaTeX 重新编译。至少编译两次，直到目录和交叉引用稳定。
- `data/curated.json` 保存合并的校对题库，`data/problems.json` 保存拆分后的题目、最终题号与来源。
- `qa/` 保存本书的构建、目录与视觉验收记录。804 页沿用已验证的 OCR 校对账本，第 14 章的 55 页保有原始识别结果并完成核验。[归档核验记录](../qa/archived-ocr-reviews.json)

编译环境与从校对数据重新生成的步骤见 [仓库说明](../README.md)。使用许可见 [使用许可](../LICENSE.md)。
