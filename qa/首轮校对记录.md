# 首轮校对记录

## 范围与题量

本轮从五份教材中选择 16 个 PDF 物理页面。页面编号均从 1 起算，包含书前封面、版权页和目录；不使用书页上印刷的页码作为来源编号。原始教材文件的完整 SHA-256 保存在 config/sample-inventory.json。

| 项目与来源 | 物理页 | 校对后的内容 | 拆分后题数 |
| --- | --- | --- | ---: |
| 讲义第一册 | 24–27 | 5 个例题；26–27 页只有理论与证明，未编造题目 | 5 |
| 讲义第二册 | 22–23 | 3 个例题；22 页用于补足正交基约定 | 3 |
| 讲义第三册 | 13–15 | 2 个说明性例题、10 道节末原题 | 14 |
| 教程上册 | 26–29 | 4 个例题、7 道节末原题 | 15 |
| 教程下册 | 19–21 | 3 个例题；21 页为证明和正文讨论 | 3 |

《讲义》20 道选定原题拆为 22 题，《教程》14 道选定原题拆为 18 题。两份成品各 8 页，含 1 页说明与目录。常规页面分别最多 4 题和 3 题；章节末页可不足额，长题独页。

## 内容处理

PaddleOCR 负责布局、文字和公式的初步识别。校对时对照原 PDF 页图，逐题整理为 data/curated.json；所有证明、解答、页眉页脚和与题目无关的正文均剔除。机器原文保留在本地 data/ocr_raw/，不直接进入成品。

本轮观察到的识别错误包括：将两道相邻例题合成一个段落、重复数列或公式、漏掉极限下标，以及把行内文字混入 LaTeX。已按源页核对收录内容；不能由此推断未处理页面的准确率。没有测算整书 OCR 识别率。

### 校订与上下文约定

- 讲义 8.3：原文等号条件为存在实数 λ 使 a_i=λb_i，遗漏 b 为零向量而 a 非零时的等号情形。改为“两向量线性相关”，题号旁标注“校订”。来源为第二册物理第 23 页。
- 讲义 14.14：回查第三册物理第 9 页，原书把“可数”定义为与正整数集一一对应，把有限或可数合称“至多可数”。因此原题在原书约定下成立。题干写明“可数无穷集合”只是补出约定，不作为原书错误，不标“校订”。
- 第三册采用正整数作为自然数的约定，14.1 的题干已明确写出。
- 原题中要求判断真假或否定的命题按原意保留，不把它们当成教材断言擅自改正。

### 小问与跨页

- 讲义的 6 个小问拆成 2 题，4 个小问拆成 2 题；教程的 10 个小问拆成 4 题，5 个小问拆成 2 题。
- 每组重复必要的公共题干，小问重新从（1）编号，避免残留原始题号。
- 讲义 14.3–14.4 的原题末个小问续到下一页，两题来源均为第三册物理第 14 页。
- 教程 1.15 的求证结论续到下一页，来源记上册物理第 28 页，并独占一页。
- 教程 10.3 在下册物理第 19 页末以“设”开头，公式与问句续于下一页，来源仍记第 19 页。

### 图片与范围限制

选中的题目均可由文字和公式完整表述，没有必须保留的题图。教材出现的数轴和积分区域图位于讲解或解答中，本轮未放入成品。程序支持按源 PDF 坐标裁剪必要题图并按最终题号命名，但这条分支尚未用真实题图完成验收。

本轮覆盖例题、节末练习、纯正文排除、多小问、跨页、说明性例题改写与长题独页。尚未验证整章的漏题率、全部章末练习、复杂必要配图及多页超长题。这些必须在整书生产时单独核查；本轮成果不是整书完成证明。

## 环境与复现

- Python 3.12 独立虚拟环境；PaddleOCR 3.3.2、PaddlePaddle 3.2.2（CPU）、PaddleX 3.3.10；完整版本见 requirements-lock.txt。
- 识别模型：PP-DocLayout-M、PP-OCRv5_mobile_det、PP-OCRv5_server_rec、PP-FormulaNet_plus-S。模型缓存不提交。
- 已安装 TeX Live 2026，使用 XeLaTeX、ctex 与 Fandol 字体。A4 单栏、两侧 22 mm、上下 23 mm；题目之间留出作答空白，样式参考用户提供的版式。
- 程序逐题测量高度后分页，再连续编译两次；最终文件位于各项目根目录的 main.pdf。
- 6 项规则测试检查小问不丢失、不重复，来源首物理页保持不变，未校对数据拒绝发布，最终编号连续，长题独页与章节标题占位。
- 本地 .gitignore 已用真实 Git check-ignore 在隔离的临时仓库验证：源教材、OCR、模型与构建文件被排除，main.pdf、题目数据、章节源码和必要配图保持可提交。

16 个源页面的 OCR 均已完成，总体验收通过；五份源 PDF 的 SHA-256 与处理前一致。两份 PDF 均完成两次 XeLaTeX 编译，没有溢出、缺字或未定义命令的日志警告，全部 16 个成品页面已查看渲染图。

机器验收结果见 sample-audit.json、gitignore-check.json 及两项目 qa/build-report.json；视觉验收和对应成品的 SHA-256 见 visual-review.json。视觉检查不能由编译通过替代。

## 后续整书与发布

整书仍需逐章识别、校对和漏题核查，并补做含必要题图与章末题的样本。公开分享前还需落实第三方教材内容的传播依据；本仓库原创部分的非商业许可不会替代教材授权。

本地目录目前未接入远程 Git 历史；此前 HTTPS 访问 GitHub 超时，尚未核验远程现有 .gitignore，也没有提交、推送或改变远程可见性。连接恢复后，应先读取远程文件与分支，再合并本地成果，保留远程历史。认证可使用用户配置的 GitHub 凭据或 SSH 公钥；无需向助手发送私钥。
