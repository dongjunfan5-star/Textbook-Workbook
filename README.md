# Textbook-Workbook
## 项目目标
本项目致力于生成数理教材的做题本，以便于本科学生较有条理地对教材习题进行集中练习。

项目遵循以下原则：

原文优先： 不擅自改写题目，不根据上下文猜测无法识别的内容。

可追溯： 每道题尽可能关联原教材页码、原始题号和校对记录。

可恢复： 按章节处理，失败后可以从未完成的章节继续。

可复现： 保留配置、结构化数据、LaTeX 源文件和构建脚本。

质量优先： OCR 结果必须经过检查，编译成功不代表题目内容正确。

保护原始资料： 原始教材仅作为只读输入，不允许脚本覆盖或删除。

本仓库中存放了我用OCR和LaTeX工具自动化重构的各种做题本。所有编码均已开源，并已提供编译好的PDF下载。
